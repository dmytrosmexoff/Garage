# Garage Apps: community app store для Umbrel

Содержит приложение **Garage Journal** (`garage-vehicle-tracker`): веб-интерфейс + Node.js API + MySQL 8.

## Установка
1. Создайте репозиторий на GitHub и загрузите в его корень содержимое этой папки
   (`umbrel-app-store.yml` и папку `garage-vehicle-tracker`).
2. В `garage-vehicle-tracker/umbrel-app.yml` замените YOUR_NAME и ссылки на свои.
3. В Umbrel: App Store → меню «⋯» → Community App Stores → вставьте ссылку на репозиторий.
4. Откройте «Garage Apps», установите Garage Journal.

Первый запуск занимает 1-2 минуты: скачиваются образы, MySQL создаёт базу, Node ставит драйвер mysql2.

## Данные
Все данные лежат в MySQL (база `garage`): vehicles, parts, part_history, mileage_log, meta.
Файлы базы: `~/umbrel/app-data/garage-vehicle-tracker/data/mysql`.

## Первый запуск (версия 1.1)
1. Откроется экран «Подключение к базе данных». Оставьте «Встроенная база Umbrel» или снимите галочку и укажите свой MySQL (адрес, порт, база, логин, пароль).
   - «Проверить подключение» проверяет доступ, «Создать пустую базу» создаёт базу и таблицы, «Сохранить и продолжить» запоминает настройки.
2. Создайте первого пользователя (он администратор). Остальные регистрируются сами, у каждого свой транспорт.
3. Настройки базы позже: главная страница → Настройки → «Подключение к базе» (только администратор).
Настройки подключения хранятся в `~/umbrel/app-data/garage-vehicle-tracker/data/config/db.json`.

## Версия 1.2
- Переводы: `garage-vehicle-tracker/server/public/i18n.js` (русский, English, Українська, 日本語). Строки хранятся как `[русский оригинал, English, Українська, 日本語]`.

## Версия 1.3: мастер, уведомления, публичный адрес
- **Чек-лист с QR-кодом.** При печати чек-листа создаётся ссылка `https://ваш-домен/m/<токен>` и PIN из 4 цифр (печатаются на листе). Мастер отмечает работы на своём телефоне и нажимает «Работа окончена». Владелец видит «Ответ мастера» на главной, проверяет и нажимает «Принять»: только тогда записи попадают в историю, а ссылка закрывается. После 5 неверных PIN ссылка блокируется. Новая печать закрывает прежнюю открытую ссылку.
- **Публичный адрес** (главная → Настройки → «Публичный адрес и доступ», только администратор): адрес для QR-кодов (например `https://auto.magtape.cloud`) и автоматическое перенаправление с локального адреса. Если публичный адрес не отвечает, приложение остаётся на локальном. Чтобы открыть приложение локально без перенаправления, добавьте `?local=1`.
- **Cloudflare Tunnel** должен вести на порт приложения (3000). В `docker-compose.yml` отключён запрос пароля Umbrel (`PROXY_AUTH_ADD: "false"`): защита идёт через собственный вход приложения, регистрация новых пользователей по умолчанию закрыта (включается в том же окне администратора).
- **Push-уведомления** (Web Push): включаются на каждом устройстве в «Настройки → Уведомления». Нужен https-адрес. На iPhone сайт сначала добавляют на экран «Домой» (iOS 16.4+). Ключи создаются автоматически; при первом запуске версии 1.3 `npm install` докачает пакет `web-push`.

## Версия 1.4
- Главная: «Настройки аккаунта» (язык, уведомления, экспорт и импорт, установка приложения, выход) и «Админ-настройки» (подключение к базе, публичный адрес, регистрация).
- «Настройки авто» у каждого транспорта: данные, чек-лист, отчёт, ссылки для мастера, замена панели, удаление.
- Системные оповещения видны только администратору, с пометкой «Системное», не пропадают сами и закрываются крестиком.
- Кнопка проверки (логотип Check Engine) спрашивает подтверждение. Проверка отмечает деталь «проверено» и добавляет 20% интервала к оставшемуся пробегу; ответственность за решение остаётся за владельцем.
- Установка приложения: на Android и в Chrome кнопка вызывает системный запрос установки. На iPhone (Safari) сайт нельзя установить кнопкой: нужен пункт «Поделиться → На экран «Домой»».
- Уведомления: для установленного приложения запрашиваются при первом открытии (нужно одно нажатие «Включить»; браузер не даёт включить их без вашего действия).

## Версия 1.5
- **Пункты для типа транспорта** (админ-настройки → «Пункты для транспорта»): название на русском, английском, украинском и японском, категория, интервал в км и/или месяцах. Пункт добавляется всем транспортам этого типа (уже созданным и новым) и появляется у всех пользователей, в том числе незарегистрированных (список берётся публично). Скрыть пункт можно там же: скрытый не добавляется новым транспортам, уже сделанные записи сохраняются.
- **QR для термопринтера** (настройки авто, только администратор): скачивается PNG 640×260 с QR, PIN и названием. Печатается на чековом принтере как изображение. Лист создаёт ссылку мастера так же, как печать чек-листа, и закрывает прежнюю открытую.
- **Мастер до первой отметки «Сделано»** может убрать позицию из списка или добавить свою (название). После первой отметки список фиксируется и на сервере (ответ 409).
- **Уведомления**: «Каждую неделю» (выбор дней недели) или «Раз в месяц» (до 4 чисел месяца). Раз в месяц приходят только просроченные детали. Страховка и техосмотр приходят по своему графику.
- В базе новые таблицы: `custom_items`; у пользователей поля `push_mode` и `push_mdays`. При обновлении создаются сами.

## Версия 1.6
- **Запросы мастера.** Мастер добавляет или убирает пункт только через запрос с ценой и комментарием (комментарий обязателен, если цена больше 0). Пункт висит «ожидает одобрения», пока вы не примете или не отклоните. Работы, которые вы не приняли, мастер не выполняет.
- **Плашки на сайте** (на любой странице): жёлтая для бесплатного изменения, красная для платного запроса. Нажатие открывает «Запросы мастера».
- **Напоминания.** Платные запросы без ответа приходят push каждый час с 9:00 до 18:00, включая выходные. Бесплатное изменение приходит один раз.
- **Изменение списка** до первой отметки «Сделано»: в «Ссылки для мастера» → «Изменить список». После отметки список фиксируется.
- **QR-лист** рядом с «Чек-лист для мастерской», доступен всем: PNG (горизонтальный прямоугольник с QR, «Введите PIN-код» и ссылкой) или PDF.
- **Данные для мастера** (настройки авто): госномер, номер рамы, объём двигателя и дата техосмотра. Мастер видит их только после ввода PIN. Они входят в резервную копию JSON.
- На странице мастера до PIN показываются только тип и название транспорта.
